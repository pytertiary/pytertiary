# pytertiary
PyTertiary is a Python application for Windows and MacOS designed to automate known exploits and vulnerabilities reported. Made in Texas, not China.

What PyTertiary specifically does and offers is not public information due the possibility of having everything patched and PyTertiary blocked.

# KEY SYSTEM

PyTertiary uses a key system in a 32 digit alphanumerical format, like `XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX` or `is81MS91-juAm34Ju-IAmc31Op-Db81230F` (not redeemable) to buy a key download the app at ____________ and download PyTertiary.pyc 

# Getting a key

To get a key you must first download PyTertiary.pyc and run it. It will show you how to make an account or log back in. Afterwards it requests a key. No key? Click `I don't have a key` and it will show you a screen with a QR code to T3's (PyTertiary's) official CashApp account. You will also be given a Payment ID at the top formatted like `PAYID-XXXX-XXXX-XXXX-XXXX` or `PAYID-dj1I-Is90-lOPa-82jI` (not a real Payment ID). When buying a key you **MUST** add in into the comment / note section of the payment area.
